### 2) CogniSense
Multimodal edge AI project focused on cognitive state monitoring using sensor fusion and reliability-aware inference.

<p>
  <img src="https://img.shields.io/badge/Real-time-Multimodal-22C55E" />
  <img src="https://img.shields.io/badge/Explainability-XAI-FFB703" />
  <img src="https://img.shields.io/badge/React-Frontend-61DAFB?logo=react&logoColor=black" />
  <img src="https://img.shields.io/badge/TypeScript-Frontend-3178C6?logo=typescript&logoColor=white" />
</p>

- Built a multimodal sensor-fusion workflow with wearable and environmental data streams.
- Designed reliability-gated inference with confidence scoring, sensor staleness handling, and graceful degradation during dropout.
- Included feature importance analysis and live monitoring for explainability and system observability.
- Project-reported results: 94.2% test accuracy, 12.4 ms average inference latency, 38.7 ms P99 latency, sustained predictions through 1.5 seconds of sensor dropout.
- Repository link — https://github.com/codinginsha/cognisense
